# AGENTS.md

A SvelteKit static-site template for interactive, type-checkable Agda in the
browser. The Agda Language Server runs as a WASM worker; the runtime binaries
are downloaded at build time from a pinned
[`agda-als-dist`](https://github.com/jespercockx/agda-als-dist) release. This
repo is the canonical starter; `jespercockx/plfa-playground` is the worked
example.

- User-facing docs (config reference, interfaces modes, content authoring):
  [`README.md`](README.md)
- Internals (thread model, boot flow, invariants): [`ARCHITECTURE.md`](ARCHITECTURE.md)

## Commands

```sh
npm ci            # then:
npm run dev       # predev downloads runtime (cached in .runtime-cache/) + syncs content
npm run check     # svelte-check, must be 0 errors / 0 warnings
npm test          # vitest
npm run build     # sync-runtime + sync-content + vite build, output in build/
```

Browser regression check (needs a running `npm run dev` and local
Chromium/Chrome):

```sh
PLAYGROUND_URL=http://127.0.0.1:5173 npm run benchmark:content
# CHAPTERS=A,B narrows; CHROME_EXECUTABLE overrides the browser path
```

Run this after any change to the controller, drive worker, transport, or
`browser-source.js`: the unit tests do not cover the wasm boot path.

## Generated files — do not edit or commit

- `src/lib/runtime-manifest.ts` — generated by `scripts/sync-runtime.mjs`
- `static/als-*.wasm*`, `static/agda-data.zip`, `static/agda-stdlib-*.zip`,
  `static/stdlib-interfaces/`, `static/content/*` (all generated; see
  `.gitignore`). Exception: `static/content/interfaces/` holds committable
  precompiled archives.
- `.runtime-cache/` — verified download cache

## Hard constraints

- **Vite is capped below 8.3 on purpose.** Vite 8.3+ breaks the
  `?worker&inline` wasm worker (UI hangs on "Starting Agda 100%"). See the
  comment in `package.json`. Do not bump without testing the full browser boot.
- **All runtime fetches must go through `asset()` from `$app/paths`.** The
  GitHub Pages deploy builds with `BASE_PATH=/<repo-name>`; a hardcoded
  absolute URL breaks the live site.
- **COOP/COEP is required** (`SharedArrayBuffer`): `static/coi-serviceworker.js`
  supplies the headers. One automatic reload on first visit is expected, and
  the ALS worker refuses to run without `crossOriginIsolated`.
- **Agda 2.8.0+ only**; the version is pinned via `runtime.release` in
  `playground.config.json` (never hardcode versions, sizes, or cache-bust
  strings in app code).
- **`importRewrite` replacements must be exactly the same UTF-8 byte width**
  as the name they replace, or highlighting, goals, and scroll sync misalign.

## Changing content or config

`content/` and `playground.config.json` are the inputs; `npm run sync:content`
regenerates `static/content/`. `dev` and `build` run it automatically. The
optional precompile step needs a local native Agda of the pinned version
(`npm run precompile:content -- /path/to/agda`).

## Deployment

CI runs on every push/PR; `deploy-pages.yml` deploys to GitHub Pages via
`workflow_run` on CI success. The `workflows: [CI]` filter in that trigger and
the branch filters in both workflows must be kept in sync if the CI name or
`master` ever changes.
